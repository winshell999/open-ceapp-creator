# Open CEAPP Creator

A complete CEAPP authoring skill with source-backed bridge contracts, reusable adapter, nine runnable source demos, a local standard UI and executable validation gates.

Start with SKILL.md. Open assets/starter/index.html to inspect the full Lab in browser-preview mode, or package exactly one assets/demos/<profile> directory using the CanEngine client.
Run the generation/validation commands documented in SKILL.md. Review reports/VALIDATION_REPORT.md and references/testing-and-acceptance.md before describing anything as native-tested.

This refactor targets the CanEngine 1.7.3 source baseline inspected on 2026-09-26. It does not change the CanEngine host, connect an AI provider, transmit to a phone, or install a signed CEAPP on behalf of the user.

The original skill and assets were backed up in the task Canvas under backups/pre-refactor-20260926. The distribution contains the updated reusable skill, not that private development backup.
