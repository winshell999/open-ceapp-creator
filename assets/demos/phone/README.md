# CEAPP phone demo

Profile: `phone`. This is CEAPP SOURCE, not a signed .ceapp.

1. Open index.html for the browser-only UI and local file preview.
2. Drag this directory into CanEngine packaging/signing, install and open it.
3. On Overview, inspect host identity. Use feature buttons individually.
4. For Python: Files > Sample file, Python tasks > Inspect file, then export.
5. AI, notifications and phone send occur only after explicit clicks/confirmation.
6. Local database: save/read/list/delete the fixed demo note. Shared IDs must be configured.

Browser appearance and simulated tests do not prove native host acceptance.
No user API keys, signing keys or provider URLs belong in this source.
The app shell is local; AI/network/phone features are not guaranteed offline.
The no-op command in UI-only profiles satisfies the packer and is never executed.
